FAQ

常见问题

那些库各自忠于一种平台语言。Prify 在令牌层做了统一抽象：同一套语义色、圆角、动效曲线，既能渲染成 M3 的表达，也能渲染成 Fluent 的表达，还能像本页一样把两者揉在一起。

内核是标准 Web Components（Shadow DOM），天然框架无关；官方提供 React / Vue / Svelte 的类型包装与 Figma 双向同步插件。

取色引擎会计算 HCT 色彩空间的 tonal 色阶，并强制校验文本对比度 ≥ 4.5:1（AA）。不达标的组合会被自动降级到邻近 tone，你永远拿到的都是合法色板。

本项目采用 PolyForm Noncommercial 1.0.0：非商业用途免费，商业用途需事先取得作者书面授权。专业版 / 企业版增加的是闭源高级组件、Figma 套件与 SLA 支持，按席位订阅，随时可退订。
